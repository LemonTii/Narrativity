Narrativity is a web-based application designed to harness the power of Natural Language Processing (NLP) for storytelling. Built on Flask, it interfaces with a generated model to create stories based on user prompts, providing a seamless and interactive experience for users interested in exploring the boundaries of automated creative writing.

## Prerequisites

Before setting up Narrativity, ensure your system meets the following requirements:

- Python 3.6 or later
- pip (Python package installer)

Knowledge of Python and basic command-line navigation is recommended for a smooth setup process.

## Installation

Follow these steps to get Narrativity up and running on your system:

1. **Clone or Download the Repository**

   Begin by cloning this repository to your local machine

2. **Navigate to the Project Directory**

   Open your terminal or command prompt and change into the project directory.

3. **Set Up a Virtual Environment** (Optional)

   It's a good practice to use a virtual environment for Python projects. Create one by running:

   ```sh
   python -m venv venv
   ```
    Activate the virtual environment (On Windows):
    ```sh
    .\venv\Scripts\activate
    ```
    Activate the virtual environment (On Unix or MacOS):
    ```sh
    source venv/bin/activate
    ```
    install all necessary Python packages with pip:
    ```sh
    pip install -r requirements.txt
    ```
## Running Narrativity
```sh
    cd /src
    python app.py
```
This command starts a Flask server. Interact with Narrativity by:

1. Opening your web browser and navigating to http://127.0.0.1:5000/.
2. Inputting your storytelling prompt in the provided form.
3. Submitting the form to receive a unique story generated by the model, displayed directly below the input form.
